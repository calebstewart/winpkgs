Nothing here is built. A package in home.packages or environment.systemPackages is read for its annotation and installed the way the annotation says: through winget, from the font files nixpkgs fetches, or from a release archive copied under %LOCALAPPDATA%\Programs. A name that is not in these tables is an evaluation error naming it; software winget has and nixpkgs does not is {% if lib_url %}pkgs.winpkgs.fromWinget "Publisher.Id"{% else %}pkgs.winpkgs.fromWinget "Publisher.Id"{% endif %}, and a font or a zip the tables lack is pkgs.winpkgs.font or pkgs.winpkgs.portable.

Fonts

A font is installed from its files: for the user from home.packages, machine-wide from fonts.packages. The closure carries the files; the runtime copies and registers them, and removes them when the package leaves the configuration.

Portable

Programs that are not on winget and ship as a zip of files. A home configuration copies one to %LOCALAPPDATA%\Programs\<name> and puts that directory on the user's PATH; the version is pinned in the overlay.
